# Contributing to Vchat

Thank you for your interest in contributing to Vchat! 🎉

## How to Contribute

### 🐛 Reporting Bugs

1. Check if the bug has already been reported in [Issues](https://github.com/Trimpu/Vchat/issues)
2. If not, create a new issue with:
   - Clear title and description
   - Steps to reproduce
   - Expected vs actual behavior
   - Screenshots if applicable
   - Browser and OS information

### 💡 Suggesting Features

1. Open a new issue with the "Feature Request" label
2. Describe the feature and why it would be useful
3. Include mockups or examples if possible

### 🔧 Pull Requests

1. Fork the repository
2. Create a new branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. Make your changes
4. Test thoroughly
5. Commit with clear messages:
   ```bash
   git commit -m "Add: brief description of changes"
   ```
6. Push to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```
7. Open a Pull Request with:
   - Clear description of changes
   - Reference to related issues
   - Screenshots/GIFs of UI changes

## 📝 Code Style

- Use ES6+ JavaScript features
- Follow existing code formatting
- Add comments for complex logic
- Use meaningful variable names
- Keep functions small and focused

### CSS Guidelines
- Use CSS variables for colors
- Maintain glassmorphism aesthetic
- Ensure responsive design
- Test on multiple devices

### JavaScript Guidelines
- Use async/await for promises
- Handle errors gracefully
- Add loading states for async operations
- Keep code modular

## 🧪 Testing

Before submitting a PR, test:
- ✅ Sign in/out functionality
- ✅ Chat creation and switching
- ✅ Message sending
- ✅ Image generation
- ✅ Chat history persistence
- ✅ Mobile responsiveness
- ✅ All button interactions

## 🎨 Design Guidelines

- Follow iOS design principles
- Maintain consistent spacing
- Use smooth animations (0.3s cubic-bezier)
- Ensure high contrast for accessibility
- Test in dark mode

## 📚 Adding New Features

When adding new Puter.js features:

1. Check [Puter.js docs](https://docs.puter.com)
2. Add UI elements in `index.html`
3. Add styles in `styles.css`
4. Implement logic in `app.js`
5. Update README with new features
6. Test thoroughly

### Example Features to Add:
- Speech-to-text input
- Text-to-speech responses
- Image analysis (img2txt)
- Video generation
- File uploads
- Export chat functionality

## 🤝 Code Review Process

1. PRs will be reviewed within 3-5 days
2. Feedback will be provided if changes needed
3. Once approved, PR will be merged
4. Your contribution will be credited!
